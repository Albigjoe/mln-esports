# MLN Esports

A web application for MLN Esports built using Next.js and TypeScript. It features tournament bracket views, match statistic tracking, squad registration, and player profile configuration.

The live application is hosted at [https://mln-esports.vercel.app](https://mln-esports.vercel.app).

## Getting Started

First, run the development server:

```bash
npm run dev
```
